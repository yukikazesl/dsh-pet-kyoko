## 打字互动 / 扩待机（13–15）

1. 用 13/14/15 号 txt 生成绿幕 mp4，放入 `video/`。
2. 跑素材链后把 webm 拷进 `kyoko-pack/kyoko-animation/` 与 `~/.dsh/dsh-pet/pet/kyoko-animation/`。
3. 把 `kyoko-config.json` 的 `animations.events.typing` 改为 `["原地打字敲键盘"]`，并在 `idle` 里追加 `待机眨眼发呆`、`待机轻微晃腿`。
4. 刷新 DSH 或重启 `dsh web`。

未生成打字素材前，`typing` 暂用已有「玩游戏气急败坏」顶上，方便先验证按键触发。

## 来杯好茶摇一摇（16）

月薪喵「来杯好茶」那种举杯左右摇一摇。生成 `来杯好茶摇一摇.mp4` → 跑素材链 → webm 放入 animation 目录后，在 `kyoko-config.json` 的 `animations.categories`「日常」里追加 `"来杯好茶摇一摇"`，刷新即可。
