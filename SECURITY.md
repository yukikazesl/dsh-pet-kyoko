# Security Policy

## Supported versions

This is a community fork of dsh-pet. Security fixes are applied on a best-effort basis to the default branch.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Use GitHub **Private vulnerability reporting** (if enabled on the repository), or contact the maintainers via the email listed on the repository profile / latest release notes.

Include:

- affected component (`dsh-pet` host/client, desktop helper, scripts, etc.)
- reproduction steps
- impact assessment

We will try to acknowledge reports within a reasonable time and coordinate disclosure.
